Import files

Drop any mix of: daily Energy Log (.xls), Statistics-SERC (.xls), IEX DAM / RTM snapshot (.xlsx), the KSEBL LGB projection workbook (.xlsx), the Purchase & Surrender workbook (.xlsx), daily SLDC PDF (the same file is also saved as that day's Load curve – no separate upload), or a .zip of them. Files are recognised automatically. Import once – the numbers are saved to the shared database and every section updates for everyone viewing the dashboard. Every section (Summary, Demand, Hydro, IEX, Data) updates from the same data. Files already imported are skipped automatically; a changed file or a newer version of the monthly workbook is re-read and overwrites the days it contains. Energy Log file names need the date (e.g. Energy_log_for03_11_2026.xls).
